📚 Quiz Agent — RAG par Thème
Le RAG intervient ici pour sourcer les questions selon le thème choisi
sequenceDiagram
    participant U as Utilisateur
    participant Q as quizAgent
    participant R as ragService
    participant M as MCP Server
    participant G as Gemini

    U->>Q: "Génère un quiz sur le Hajj"
    Q->>R: fetchIslamicRAGContext("Hajj")
    R->>M: executeMcpTool(search_quran, search_hadiths, search_duas)
    M-->>R: Versets et hadiths sur le Hajj
    R-->>Q: Contexte documentaire enrichi
    Q->>G: Prompt de génération de quiz avec sources fiables
    G-->>Q: Question structurée (options, réponse, explication)
    Q-->>U: ✅ Quiz interactif prêt

✨ Architecture 100% Propre :
• Assistant : Gemini décide directement des actions (zéro appel aveugle, zéro regex bricolée).
• Quiz : Le RAG enrichit les thèmes de questions de manière ciblée.
• MCP Server : Couche universelle et unique d'accès aux services.
