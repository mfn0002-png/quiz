AVANT Gemini - Le RAG prepare le contexte
Le RAG cherche des sources authentiques pour enrichir la question AVANT de l'envoyer a Gemini
sequenceDiagram
    participant U as Utilisateur
    participant A as Agent
    participant R as RAG
    participant M as MCP Server
    participant S as Services / APIs

    U->>A: Quelle est l invocation pour voyager ?

    rect rgba(74, 158, 255, 0.1)
    Note over A,S: AVANT Gemini - Le RAG enrichit le prompt
    A->>R: fetchIslamicRAGContext voyage
    R->>R: Cherche dans la base locale
    R-->>R: Pas trouve localement
    R->>M: executeMcpTool search_duas topic voyage
    M->>S: fetchDuas voyage
    S-->>M: Donnees brutes de API
    M-->>R: Dua formatee du voyage
    R->>M: executeMcpTool search_hadiths query travel
    M->>S: fetchHadiths travel
    S-->>M: Hadiths bruts
    M-->>R: Hadiths formates
    R-->>A: Contexte combine duas + hadiths + versets
    end

    Note over A: Le message est maintenant ENRICHI

    A->>A: Envoie le message enrichi a Gemini
    Note over A: Gemini redige une reponse savante avec les VRAIES sources

    A-->>U: Reponse avec citations authentiques

APRES Gemini - Function Calling via Outils MCP
Gemini DECIDE d utiliser un outil quand il doit executer une action calcul quiz horaires
sequenceDiagram
    participant U as Utilisateur
    participant A as Agent
    participant R as RAG
    participant G as Gemini
    participant M as MCP Server
    participant S as Services

    U->>A: Calcule ma zakat sur 10000 EUR

    rect rgba(74, 158, 255, 0.1)
    Note over A,R: AVANT - RAG cherche du contexte sur la Zakat
    A->>R: fetchIslamicRAGContext zakat
    R->>R: Trouve dans base locale !
    R-->>A: Coran 2:43 et Hadith Bukhari sur la Zakat
    end

    A->>G: Message enrichi avec contexte RAG

    rect rgba(46, 204, 113, 0.1)
    Note over G: Gemini DECIDE avoir besoin de calculate_zakat
    G-->>A: functionCall calculate_zakat amount 10000 currency EUR

    Note over A,S: APRES - Agent execute outil via MCP
    A->>M: executeMcpTool calculate_zakat amount 10000
    M->>S: calculateZakat amount 10000 currency EUR
    S-->>M: zakatAmount 250 exceedsNisab true
    M-->>A: Zakat = 250 EUR - Depasse le Nisab
    end

    A-->>U: Votre Zakat est de 250 EUR avec explications

Aspect RAG (ragService) Outils MCP (function calling)
Quand ? AVANT appel a Gemini APRES que Gemini decide
Qui decide ? Agent automatiquement a chaque requete Gemini choisit outil necessaire
But Enrichir le prompt avec du contexte authentique Executer une action precise
Exemple Injecter versets du Coran et hadiths pertinents Calculer la Zakat, afficher horaires, lancer quiz
Analogie Notes de cours sur la table d examen Calculatrice autorisee pendant l examen
Sans lui ? Gemini invente de faux hadiths et versets Gemini ne peut pas agir calcul quiz etc

Le RAG donne a Gemini les bonnes references AVANT qu il reponde (anti-hallucination).
Les outils MCP permettent a Gemini d AGIR quand il en a besoin (calcul, quiz, horaires).

Les deux passent par le MCP Server, mais a des moments et pour des raisons differentes.
Complementaires, pas redondants.
